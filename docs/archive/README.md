# Historical dashboard

`hal-dashboard-2026-10-17.html` preserves the uploaded dashboard and its dated
commentary. It is an archive, not the app entry point, and is not served by the
production gateway. Its old position defaults, model prices, fixed IVs, dates,
and narrative are not used as current market evidence or imported as holdings.

The active app starts from the root `index.html` and `src/main.tsx`, with the
Node gateway launching the private Python worker. See the root README.
